# AuraGlobal — Design & Conversion NO-GOs

These rules are mandatory for every new page, component and mobile pass.

## Readability
- Never ship important text that requires zooming or squinting.
- Mobile body copy: minimum 14px where it carries buying information.
- Mobile labels/meta: minimum 11px; CTA/link copy: minimum 13px.
- Normal text must maintain strong contrast against its background. Never grey-on-grey.
- Text on images needs a dark/solid overlay behind the text.
- Never hide or truncate prices, specs, model names, discounts or comparison values.

## Responsive layout
- Never force technical/product comparison data into 3 tiny columns on phones.
- Comparison cards on mobile should use full readable width.
- No overlapping absolute/floating cards unless collision-safe at 320–430px.
- No horizontal page overflow. Horizontal scrolling is allowed only inside intentional carousels/tables.
- Tables must be readable or explicitly horizontally scrollable.

## Images & video
- No unrelated stock imagery.
- Every image must support the exact product, use case, ingredient or emotion being discussed.
- Product imagery must never imply that a generic image is the real product.
- Videos must be directly relevant to the product/use case and must have readable overlays.
- Above-the-fold product/category pages should create emotion immediately without hiding the buying decision.

## AuraGlobal value
- Never build a page that merely restates the merchant shop.
- Every partner/category page must answer a purchase question: which option, for whom, why, and what changes the decision?
- Show useful comparisons such as price/unit, size, weight, range, use case, key feature or current verified deal where appropriate.
- Provide a clear internal comparison path before or alongside outbound merchant links.

## Deals
- Never publish an unverified discount.
- Every time-limited deal must have a verified date/source and a start/end date when known.
- Expired deals must disappear automatically.
- Never leave a historical promotion labeled as current.
- Seasonal homepage emphasis should prioritize current opportunities (Prime Day, Black Friday, end-of-season, etc.) over permanent brand promotion.

## Homepage scaling
- The homepage is category-, need-, search- and deal-first — not an endless brand list.
- Individual brands live inside category/decision pages and the dedicated directory.
- The homepage must remain useful at 100, 1,000+ partners.
