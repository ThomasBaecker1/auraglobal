# AuraGlobal UX / Content Guardrails

These rules are mandatory for every new page, comparison and homepage change.

## Absolute NO-GOs
- Unreadable text on images, gradients or dark/light backgrounds.
- Text that requires zooming or squinting on mobile.
- Important data hidden, clipped, overlapped or pushed outside the viewport.
- Three-column technical comparisons on small phones.
- Decorative overlays that cover prices, specs, CTAs or product names.
- Random stock imagery that does not match the product, use case or ingredient.
- Videos that are unrelated to the purchase decision.
- Brand-first homepage architecture that cannot scale beyond a small partner count.
- Permanent homepage favoritism for a brand without a current user-value reason.
- Dead links, placeholder categories, empty destinations or "coming soon" click traps.
- Unsupported prices, discounts, ratings, review counts or performance claims.
- Stale deals without a verification date or known expiry handling.
- Fake rankings, fake reviews, invented product scores or invented scarcity.
- Hiding useful comparison data merely to make mobile layouts denser.
- Visible technical affiliate jargon such as "Affiliate-Link" in normal CTA labels.
- Repetitive filler copy that merely repeats a merchant's own shop.

## Mandatory principles
1. Readability first: sufficient contrast, practical font size, clean spacing.
2. Decision value first: every comparison must answer "why use AuraGlobal instead of going directly to the merchant?"
3. Category / intent first: homepage navigation is based on what the customer wants to buy or solve.
4. Deals are allowed to spotlight brands when the deal itself is current and verified.
5. Brand directory scales separately from the homepage.
6. Every important product page needs clear paths to the merchant, without drowning the user in buttons.
7. Images create emotion but must stay relevant to the actual category/use case.
8. Videos must explain usage, context, differences or the product experience.
9. Mobile must show all critical specs and CTAs without clipping or overlap.
10. All affiliate destination URLs must use real approved tracking links; never fabricate them.
11. Deal cards need verification date/conditions and should auto-expire when a reliable end date is known.
12. AuraGlobal must add value through comparison, normalization, price-per-unit logic, use-case mapping, deal detection or clearer decision paths.

## Homepage architecture
Hero / Search → Categories → Current verified deals → Decision value → Popular purchase decisions → AuraGlobal original motion / editorial inspiration → Directory / next step.

Individual brands belong on:
- deal cards when there is a verified current offer,
- category comparison pages,
- individual comparison pages,
- the scalable brand directory.

They should not permanently dominate homepage real estate simply because they are partners.
